## 1. 产品概述
AssetPulse（资产脉搏）是一款资产日均成本追踪应用，帮助用户量化每件物品的真实使用成本。通过记录购买价格、使用时长和回收金额，自动计算日均成本，让消费决策更理性。

- 核心价值：让每一笔消费都清晰可见，用数据驱动理性消费
- 目标用户：注重性价比的消费者、极简主义者、FIRE运动践行者

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册（本地应用） | 所有功能 |

### 2.2 功能模块
1. **仪表盘页**：资产总览、日均成本排行、消费趋势图表、统计摘要
2. **资产列表页**：所有物品的卡片/列表视图、筛选排序、搜索
3. **添加/编辑资产页**：表单录入物品信息、状态切换
4. **资产详情页**：单个物品详细信息、日均成本变化曲线

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 3. 核心流程

用户打开应用 → 仪表盘查看总览 → 点击添加按钮录入新物品 → 填写名称/价格/日期 → 自动计算日均成本 → 物品退役时更新状态和回收信息 → 日均成本重新计算

    "C" --> "E[查看资产列表]"

    "K" --> "L[标记已回收]"
    "K" --> "M[标记已报废]"

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深墨绿 (#0D1B1E) + 翡翠绿 (#10B981) 作为强调色
- 次要色：琥珀金 (#F59E0B) 用于警示/高日均成本
- 按钮风格：圆角微凸，柔和阴影，hover时轻微上浮
- 字体：DM Sans（正文）+ Space Grotesk（数字/标题）
- 布局风格：卡片式布局，左侧导航栏（桌面端），底部导航（移动端）
- 图标风格：线性图标（Lucide），1.5px 描边

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 仪表盘 | 统计摘要 | 4张渐变卡片，数字大字体，图标点缀，微动画 |
| 仪表盘 | 排行榜 | 横向条形图，颜色渐变表示成本高低 |
| 仪表盘 | 趋势图 | 面积图，渐变填充，平滑曲线 |
| 仪表盘 | 分布图 | 环形图，中心显示总数 |
| 资产列表 | 搜索筛选 | 搜索框+下拉筛选器，sticky顶部 |
| 资产列表 | 资产卡片 | 圆角卡片，左侧状态色条，右侧日均成本突出显示 |
| 添加/编辑 | 表单 | 分组表单，实时计算结果以卡片形式预览 |
| 资产详情 | 成本曲线 | 平滑下降曲线，标注关键节点 |

### 4.3 响应式设计
- 桌面端优先设计，最大宽度1440px居中
- 平板端：768px-1024px，导航栏折叠为汉堡菜单
- 移动端：<768px，底部Tab导航，单列卡片布局，触摸优化

### 4.4 数据持久化
- 使用 localStorage 存储所有资产数据
- 支持导出为 JSON 文件备份
- 支持从 JSON 文件导入恢复数据
